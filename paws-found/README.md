# Paws & Found

Paws & Found is a free, client-side web app that helps lost pets get home fast.

Tap the paw and the camera opens instantly — the app saves a photo of the animal with its exact GPS location and the time, because when you're passing a lost dog or cat you may only have a few seconds. Once the sighting is saved, you can see it on a map, find the nearest shelter, or share it to help the animal get home.

How to run it: open `paws-found.html` in any browser. No server, no build step, no sign-up. Everything runs in your browser. (Note: the camera needs a secure connection — it works from the live link or a local web server, not from a plain downloaded file.)
