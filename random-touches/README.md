random-touches
==============

Bored? Let's go somewhere

Random Touches is a free, client-side web app: one big randomizer. Tap a button and land somewhere random on the internet — a fun link, a fact, a video, an animal, a joke, a world record, and more. It's fast, easy, random, and entertaining.

How to run it: open `random-touches.html` in any browser. No server, no build step, no sign-up. Everything runs in your browser.

Live version: https://muse.ai/s/random-touches-uxr6xqx0enxvxexkk/T6EDrkGn3TN3RoZYlBthKzzjT3oG79L3Uae3AVeVlg4
